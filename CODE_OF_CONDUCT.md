# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful and constructive, assume good faith, and keep
discussions about the work. Harassment, personal attacks and discrimination
are not tolerated.

To report a problem, email the maintainer at the address on the GitHub
profile of [@avrahamr](https://github.com/avrahamr). Reports are handled
confidentially.
